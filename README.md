```
backend/    Laravel 12  → REST API (/api/*) + Sneat admin dashboard (/admin) + MySQL migrations & seeders
frontend/   React 18 + Vite → the public website (GSAP · ScrollTrigger · Lenis · 3D rings · live search)
docs/       01-Fullstack-Blueprint-Book.pdf        the thinking process, sequence, decisions, playbook
            02-Setup-Integration-and-Run-Guide.pdf install, integrate, e-mail, Google Sheet, deploy, troubleshoot
            google-apps-script.gs                  paste into Google Sheet → Apps Script
            nginx-api.conf                         sample production config
```

## Run it (10 minutes)

Needs: PHP 8.2+, Composer 2, MySQL 8 / MariaDB 10.6+, Node 18+.

```bash
# 1) database
mysql -u root -p -e "CREATE DATABASE portfolio CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;"

# 2) backend   (terminal 1)
cd backend
composer install
cp .env.example .env          # Windows: copy .env.example .env   → then set DB_USERNAME / DB_PASSWORD
php artisan portfolio:install # app key + tables + demo data + storage link
php artisan serve             # http://localhost:8000

# 3) frontend  (terminal 2)
cd frontend
npm install
cp .env.example .env
npm run dev                   # http://localhost:5173
```

| What | URL |
|---|---|
| Website | http://localhost:5173 |
| Admin dashboard | http://localhost:8000/admin — `admin@example.com` / `password123` (**change it**) |
| API example | http://localhost:8000/api/bootstrap |

Read **docs/02-…Guide.pdf** next (e-mail setup, Google Sheet, deployment), then **docs/01-…Book.pdf** for the method.

## What's inside (short)
* **Admin** (Sneat template): projects with huge case studies, blog posts with a rich editor (images at start / middle / end, left / right / centre, captions, code, video), categories, skills, services, timeline, FAQs, theme colours, site settings, media library, messages (+ Excel / CSV export + Google Sheet sync), subscribers, live search, animated dashboard.
* **Contact form** → saved in MySQL → e-mailed to you → row in your Google Sheet → downloadable as Excel.
* **Website**: dark/light, accent-colour picker (colours come from admin), motion on/off, smooth scroll, 3D page transitions, 3D project & blog rings, pixel-portrait hero, live search with thumbnails.
* **Demo data**: 6 projects (cover, gallery, video), 6 long blog posts with aligned images, images/videos generated by `backend/tools/generate_seed_assets.py`.

## Notes
* `backend/public/sneat/` contains the Sneat assets from the template you supplied — keep your own licence for it.
* The rich-text editor (TinyMCE, GPL edition) is bundled in `backend/public/vendor/tinymce`.
* Tested here: API + admin flows on Laravel 12 with MySQL(MariaDB) and SQLite, and the React app rendered against the live API.
